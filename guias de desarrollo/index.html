MedicDate web | Reparto interactivo

Cada integrante lleva módulos completos: página pública, pantalla privada con CRUD, API y tablas. Marca tareas, cambia de dueño un módulo y mira cómo se reparte la carga.

Orden de trabajo
  1. Fase 1, todos: crear la BD con el script v2 y subir la estructura base. Ronaldo entrega plantilla, conexión y guardias por perfil.
  2. Fase 2, en paralelo: Ronaldo hace login, recuperar y Usuarios. Leslie empieza por Especialidades (Monserrat las necesita). Arturo carga datos de ejemplo y arma la Agenda del asistente.
  3. Fase 3, en paralelo: Monserrat hace Médicos, Servicios y Consejos. Leslie sigue con Reseñas, Preguntas frecuentes, Quiénes somos y Aviso. Arturo hace el panel del médico. Ronaldo hace Inicio con el carrusel y Leslie cierra con el Panel general.
  4. Fase 4, todos: Inicio y el Panel general leen lo que publican los demás, así que se prueban al final con todo cargado; luego se revisa cada perfil de principio a fin.
